# silverblue-optimizer
Este repositório contém um script Bash para manutenção do sistema imutável Fedora Silverblue e um laboratório de segurança cibernética utilizando Distrobox. Ao invés de instalar ferramentas de pentest diretamente no SO e comprometer a estabilidade ou segurança do host, este projeto automatiza a criação de um contêiner isolado basedo em Kali Linux.
